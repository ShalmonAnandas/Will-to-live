# Will to Live

A tiny, dependency-free web app for collecting small reasons to keep going.

## Run

Open `index.html` in a browser.

For a local server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## What it includes

- A breathing guide
- Gentle grounding prompts
- A saved personal reasons list
- A small daily survival checklist

This is not medical care or crisis support. If you or someone else is in immediate danger, contact local emergency services or a trusted person right now.
